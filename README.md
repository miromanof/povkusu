# По вкусу

Браузерный прототип семейного меню на неделю и списка покупок под бюджет для Иркутска.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей, сборка и сервер не нужны. Для доступа с телефона можно опубликовать содержимое этой папки через GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Возможности

- Состав семьи, несколько детей с возрастом, число приёмов пищи и тип питания.
- Аллергены, нелюбимые продукты и собственные ограничения.
- Кухонная техника, время приготовления и домашние запасы.
- Выбор блюд свайпами, недельное меню и замена блюд.
- Корзина с округлением упаковок и весовых продуктов, расчёт бюджета.

В базе 42 варианта блюд. Из них 6 — адаптации по данным официального API TheMealDB, ещё 6 новых — авторские варианты. У адаптаций есть источник, перечень изменений, ингредиенты и краткое приготовление; данные сохранены в recipes-extra.json и встроены в index.html. Это не загрузка полного сайта в реальном времени. Свайпы задают мягкие предпочтения по ингредиентам и типу блюда, а не список разрешённых рецептов. Аллергены и продукты из раздела исключений остаются строгими ограничениями. Подбор учитывает группы основных блюд: цель — паста максимум дважды в неделю, остальные группы не чаще трёх раз, разные основы обеда и ужина. При недостатке альтернатив или бюджета приложение показывает предупреждение; после достижения разнообразия, доступного в базе, лишние деньги не расходуются. Бюджет можно пересчитать без повторных свайпов. Замена блюда сохраняет лимит, если исходная корзина в него укладывается.

Подбор использует эвристику и не гарантирует глобально минимальную стоимость. Проверки: `node tests/planner.cjs`, `node tests/check.cjs`, `node tests/catalog-check.cjs`, `node tests/stores-check.cjs`, `node tests/variety.cjs`.

## Библиотека и готовая еда

`recipes.html` открывает сохранённую библиотеку из 790 уникальных рецептов официального API TheMealDB. Есть поиск по названию и ингредиентам, категориям и проверенным адаптациям. `recipe-library.json` содержит метаданные и состав; полные инструкции доступны по ссылкам на источник. Большинство исходных рецептов пока не имеют проверенных порций, времени, техники и полного сопоставления с ценами, поэтому не попадают в автоматический расчёт. В нём используются 42 проверенных домашних варианта, включая 6 адаптаций, и отдельно готовые блюда.

«Без готовки» — независимый переключатель холодных блюд: он не сбрасывает плиту, духовку и мультиварку. Разрешение на покупку готовых блюд включается отдельно. В `prepared-food.json` проверены 4 товара «Слаты» и 1 товар «Абсолюта»; они привязаны к конкретному магазину. Подбор стремится включить до одного готового основного приёма в день с учётом бюджета. Покупка учитывает полные упаковки или вес, состав и возможные следы аллергенов. При неполном составе и любых заданных исключениях блюдо скрывается. В других магазинах готовая еда не подставляется без подтверждения.

Дополнительные проверки: `node tests/variety.cjs`, `node tests/kitchen.cjs`, `node tests/prepared.cjs`.

### Срезы цен

Используются вручную проверенные срезы цен от 25 ноября 2026 года: Слата (19 ингредиентов), METRO (20), ХлебСоль (18), Лента (16), Абсолют (20). Это выбранные товары для рецептов прототипа, а не полные каталоги. Автоматического обновления цен и наличия нет. Карты лояльности не используются. Адрес магазина и время проверки показаны в приложении. Доставка не включена.

Каталоги хранятся в JSON; приложение использует встроенную копию данных в `index.html`. При обновлении цен нужно обновлять обе копии.

## Хранение данных

Настройки и меню существуют в памяти открытой страницы. После перезагрузки они сбрасываются. Между устройствами данные не синхронизируются; список покупок можно скопировать кнопкой в приложении. Серверной базы, регистрации и ключей API нет. Шрифт загружается с Google Fonts.

Возраст влияет только на условный размер порции. Калорийность и индивидуальные медицинские рекомендации не рассчитываются.
